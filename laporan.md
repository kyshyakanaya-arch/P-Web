<h1> DESKRIPSI PROSES PENGERJAAN PROJEK UTS </h1>

Dalam pengerjaan projek UTS ini, saya memilih membuat website untuk bisnis photobooth dan photo studio dengan nama RonaRupa. Saya memilih tema tersebut karena tertarik dengan konsep fotografi yang dapat digunakan untuk mengabadikan berbagai momen, baik bersama teman, keluarga, maupun pasangan. Saya juga ingin membuat konsep photobooth yang memiliki ciri khas tersendiri dan berbeda dari photobooth pada umumnya.

Ide utama website ini terinspirasi dari budaya Indonesia, khususnya batik. Saya tertarik dengan motif batik yang memiliki beragam bentuk dan warna. Dari situ, saya ingin menggabungkan unsur tradisional dengan konsep photobooth modern agar menghasilkan tampilan yang menarik dan tetap memiliki identitas budaya Indonesia.

Pada awalnya, saya menggunakan nama CeritaRaya untuk website ini. Namun, setelah mengembangkan konsep dan desainnya, saya memutuskan untuk mengganti nama tersebut menjadi RonaRupa. Saya memilih nama RonaRupa karena terdengar lebih sederhana dan sesuai dengan konsep yang ingin saya tampilkan, yaitu perpaduan warna, bentuk, dan keindahan dalam setiap foto.

Proses pengerjaan dimulai pada tanggal 1 November. Saya mulai dengan menentukan konsep dan mencari inspirasi desain website melalui Pinterest. Dari beberapa referensi yang saya lihat, saya mencoba mengembangkan desain sendiri dengan menyesuaikannya dengan tema batik dan photobooth. Setelah itu, saya mulai membuat halaman Home sebagai halaman utama yang memperkenalkan RonaRupa. Saya mengatur tampilan awal website dengan menempatkan nama brand, deskripsi singkat, gambar, dan tombol pemesanan. Saya juga menentukan warna utama yang digunakan, yaitu biru navy, pink, cream, dan hijau lime. Kombinasi warna tersebut saya pilih agar website terlihat ceria, modern, dan tetap cocok dengan tema batik.

Setelah halaman Home selesai dibuat, saya melanjutkan dengan membuat halaman About, Package, Gallery, dan Book Now. Halaman About berisi profil dan sejarah RonaRupa, visi, misi, tujuan, serta struktur organisasi. Halaman Package menampilkan pilihan dua paket photobooth dan tiga paket photo studio beserta harga dan fasilitasnya. Halaman Gallery berisi kumpulan desain photo frame bermotif batik dan contoh foto studio. Sementara itu, halaman Book Now dibuat untuk memberikan kemudahan bagi pengunjung yang ingin melakukan pemesanan.

Dalam proses pengerjaan, saya beberapa kali melakukan perubahan pada tampilan karena hasil yang muncul terkadang belum sesuai dengan desain yang diinginkan. Saya mengatur kembali posisi tulisan, ukuran gambar, jarak antarbagian, warna, dan bentuk elemen sampai mendapatkan tampilan yang lebih sesuai. Saya juga mencari referensi dan menggunakan bantuan AI untuk mendapatkan inspirasi serta memahami solusi ketika mengalami kesulitan dalam pengerjaan.

Salah satu bagian yang cukup sulit bagi saya adalah membuat menu toggle pada tampilan HP. Saya masih mengalami kesulitan dalam memahami dan membuat fungsi JavaScript untuk menu tersebut. Karena itu, saya mencoba bertanya kepada AI mengenai cara membuat menu toggle agar ketika tombol bergambar garis tiga diklik, menu navigasi dapat muncul dan disembunyikan kembali. Dari bantuan tersebut, saya bisa mempelajari contoh kode dan mencoba menerapkannya pada website.

Selain itu, saya mengalami kendala ketika membuat tampilan website agar dapat menyesuaikan ukuran layar komputer dan HP. Ada beberapa bagian yang posisinya berubah atau keluar dari batas halaman ketika ukuran layar diperkecil. Saya juga mengalami kendala ketika mengunggah website ke GitHub Pages karena beberapa gambar tidak muncul. Saya sudah memeriksa kembali penulisan alamat dan lokasi file gambar beberapa kali, tetapi gambar masih belum berhasil ditampilkan. Untuk masalah tersebut, saya berencana bertanya kepada teman agar bisa mengetahui penyebabnya dan menemukan cara untuk memperbaikinya.
